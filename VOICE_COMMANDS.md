# Голосовой командный центр в JARVIS v2

Перенос голосового командного центра из проекта «Проект по умолчанию»
(Luxify-стиль: библиотека фраз, паки, сцены) в этот JARVIS. Добавлены файлы,
ничего существующего не переписано — только одна точка входа текста в `main.py`.

## Что появилось

| Файл | Что это |
|---|---|
| `jarvis_commands.py` | движок командного центра (библиотека, шаги, сцены) |
| `jarvis_packs.py` | 13 готовых паков (~104 команды) |
| `jarvis_voice.py` | слух/голос (в этом проекте — для голосов-профилей и озвучки шагов) |
| `jarvis_tts.py` | озвучка (Google TTS для русского, SAPI офлайн) |
| `jarvis_windows.py` | окна Windows (для шагов окна) |
| `actions/voice_command.py` | инструмент модели `voice_command` + быстрая дорожка для текста |
| `actions/voice_command_library.py` | инструмент модели `voice_command_library` (список/поиск/паки/история) |
| `skills/voice-commands/SKILL.md` | скилл для модели |
| `.jarvis/commands/library.json` | сама библиотека (все 13 паков уже установлены) |

## Как это работает — две двери, один движок

1. **Голос.** Речь идёт в Gemini Live как раньше; когда фраза похожа на
   сохранённую, модель сама вызывает инструмент `voice_command` и озвучивает
   отчёт. Если в библиотеке ничего нет — модель отвечает обычными
   инструментами.
2. **Текст.** Набранная строка, которая в точности (уверенность ≥ 0.9) является
   сохранённой фразой, выполняется локально **без** обращения к модели —
   мгновенно. Неточно/обычный текст идёт к модели как раньше.

Примеры фраз: «открой ютуб», «режим кино», «доброе утро», «сделай тише»,
«протокол гости», «сделай скриншот», «заблокируй компьютер».

## Безопасность

- Опасные шаги (выключение, сон, гибернация, блокировка, выключение монитора)
  и команды с флагом `confirm` **всегда** спрашивают через баннер подтверждения
  на HUD — и от модели, и из быстрой дорожки. Модель не может подделать
  подтверждение.
- Быстрая дорожка включается строго: порог 0.9. Отключить целиком:
  переменная окружения `JARVIS_VOICE_COMMANDS_FAST=0`.

## Как пользоваться библиотекой

- **Голосом/текстом модели:** «покажи список команд», «найди команду про ютуб»,
  «поставь пак youtube», «что я запускал последним» — она вызовет
  `voice_command_library`.
- **Сам файл:** `.jarvis/commands/library.json` — источник правды, руками лучше
  не править.
- **Правки движка** (модули `jarvis_*.py`) делаются в проекте
  «Проект по умолчанию» и копируются сюда один в один — чтобы обе машины
  (наш JARVIS и этот) понимали одни и те же фразы.

## Что не подключено (осознанно)

- Шаги `ask`/`agent` в этом проекте отвечают «агент недоступен» — слой агента
  живёт в «Проекте по умолчанию»; в v2 для ответов есть сам Gemini.
- Шаг `telegram` не подключён: у v2 свой мост
  (`plugins/telegram_remote.py`) с другим устройством безопасности.

## Запуск

Новые файлы подхватываются при **перезапуске** приложения (Python читает код
при старте). После перезапуска в журнале запуска появятся строки
`Action loaded: voice_command` и `Action loaded: voice_command_library`.

Резервная копия точки входа: `.backup/main.py.before-voice-commands`.
