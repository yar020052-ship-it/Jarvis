JARVIS Installer
================

1. Распакуй этот ZIP в любую папку
2. Запусти setup-jarvis-local.ps1 (правый клик -> Run with PowerShell)
3. Подожди установки
4. Запусти JARVIS через ярлык на Рабочем столе или из меню Пуск

Если PowerShell не даёт запустить файл, открой PowerShell в папке с JARVIS и выполни:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup-jarvis-local.ps1

Телеметрия: ошибки отправляются разработчику автоматически.
