# Генерация и редактирование изображений

Попросите JARVIS нарисовать изображение или приложите PNG, JPG либо WebP и опишите правки. Для работы используется Gemini API и ключ, сохранённый в настройках JARVIS. Ключ и изображение отправляются выбранному API-провайдеру; не прикладывайте конфиденциальные изображения, если не хотите отправлять их во внешний сервис.

Результат сохраняется в папке generated_images внутри пользовательской папки данных JARVIS и показывается в панели результата. Исходная картинка для редактирования ограничена размером 20 МБ. Каждая генерация получает отдельное имя файла, существующие изображения не перезаписываются.

Используется модель Gemini gemini-3.1-flash-image; доступность модели и генерации зависит от настроек аккаунта Google AI. Официальная документация Gemini описывает генерацию и редактирование изображений через google-genai: https://ai.google.dev/gemini-api/docs/image-generation
