# JARVIS Remote для Android

`android/` — устанавливаемое Android-приложение-компаньон. Оно открывает
мобильный интерфейс удалённого управления, который раздаёт сам JARVIS на ПК.
Экран чата загружается с компьютера, поэтому обновления интерфейса и функции,
добавленные в JARVIS, становятся доступны после обновления и перезапуска ПК-
версии. APK не нужно пересобирать для обычных изменений интерфейса JARVIS.

## Подключение

1. Телефон/планшет и ПК должны быть подключены к одной частной Wi-Fi сети.
2. На ПК включите локальный удалённый сервер перед запуском JARVIS. В PowerShell:

   ```powershell
   $env:JARVIS_ENABLE_DASHBOARD = "1"
   ```

   Затем запустите JARVIS из этого окна. Для постоянного включения задайте
   `JARVIS_ENABLE_DASHBOARD=1` в переменных среды Windows и перезапустите JARVIS.
3. В JARVIS на ПК нажмите **Remote Control**. На экране появятся адрес и
   одноразовый шестизначный код (действует 10 минут).
4. Откройте JARVIS Remote на Android, укажите показанный адрес, например
   `https://192.168.1.20:8000`, и нажмите **Открыть**.
5. Для локального самоподписанного HTTPS-сертификата приложение покажет
   адрес и SHA-256 отпечаток. Доверяйте сертификату только своего ПК; отпечаток
   запоминается для этого адреса. На странице входа введите одноразовый код.

После сопряжения приложение автоматически подключается повторно, пока работает
текущий процесс JARVIS. После перезапуска JARVIS создайте новый код сопряжения.
Не открывайте порт сервера в роутере для публичного интернета и не подключайтесь
через неизвестную Wi-Fi сеть. Если используете HTTP, вводите код только в своей
локальной сети.

## Сборка APK

Откройте каталог `android/` в Android Studio (JDK 17, Android SDK 35), дождитесь
синхронизации Gradle и выберите **Build > Build APK(s)**. Отладочный APK появится
в `android/app/build/outputs/apk/debug/app-debug.apk`.

Оболочка APK меняется редко: чат и его разметка загружаются с ПК. Изменения
Android-специфичных функций или самой оболочки требуют новой сборки и установки
APK. В этом рабочем окружении Android Studio, Java и Gradle не обнаружены, поэтому
готовый APK здесь не собран.
