# Интеграция идей AI Scientist, OpenHands и Agent Zero

JARVIS сохраняет свой Gemini Live runtime и использует подходящие механизмы этих проектов через собственные действия. Исходные репозитории не копируются и не запускаются внутри JARVIS.

| Источник | Подходящая возможность | Нативная опора в JARVIS | Что не переносится автоматически |
|---|---|---|---|
| [AI Scientist](https://github.com/SakanaAI/AI-Scientist) | План исследования, гипотезы, эксперименты, анализ результатов и отчёт | `web_search` для обзора источников; `parallel_subtasks` для независимого анализа; `dev_agent` для отдельного экспериментального проекта; краткий отчёт в ответе | Полный экспериментальный pipeline требует Linux, CUDA/PyTorch, моделей и шаблонов. Он не запускается на фоне и не считается научной валидацией JARVIS. В JARVIS есть чтение PDF, но нет отдельной функции создания научной PDF-статьи. |
| [OpenHands SDK](https://github.com/OpenHands/software-agent-sdk) | Агент для работы с кодом, изолированные workspace и REST/SDK-сервер | `project_workspace` для выбранного репозитория, применимых `AGENTS.md`, diff и подтверждаемого запуска команд; `dev_agent` для нового проекта | Полный SDK и Agent Server — отдельный стек. Локальная папка проекта JARVIS не является контейнерной песочницей. Для делегирования нужен отдельно развёрнутый и явно настроенный сервер. |
| [Agent Zero](https://github.com/agent0ai/agent-zero) | Инструменты, навыки, проекты, память, MCP и деление работы | Динамические actions и plugins, `load_skill`, постоянная память, `workflow_manager`, MCP-клиент и ограниченный `parallel_subtasks` | Agent Zero — отдельное приложение. Подзадачи JARVIS не имеют доступа к инструментам или файлам; сам Agent Zero не запускается автоматически. |

## Встроенный навык

`skills/research-and-coding-agents/SKILL.md` учит JARVIS применять доступные действия как ограниченный исследовательский и coding-agent workflow. Он отделяет подтверждённые наблюдения от гипотез, использует проектные diff и подтверждения и не приписывает JARVIS обучение модели или бесконечную самомодификацию.

## Проверка внешних репозиториев

Вызов штатного GitHub-интегратора для трёх ссылок не перенёс код:

- `SakanaAI/AI-Scientist`: найденный экспериментальный pipeline требует отдельной среды и не является функцией персонального desktop-ассистента.
- `OpenHands/software-agent-sdk`: SDK и сервер несовместимы с прямой заменой нативных действий JARVIS; подходящая локальная работа с кодом уже покрывается `project_workspace` и `dev_agent`.
- `agent0ai/agent-zero`: анализ прерван, когда у настроенных моделей Gemini исчерпалась квота. Не утверждается, что этот репозиторий прошёл интеграционное ревью.

Интегратор не исполняет исходный код GitHub. Его штатные патчи проходят проверку отдельной моделью и health-gate; после применения создаётся снимок для отката.
