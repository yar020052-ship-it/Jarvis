# Управление Android через ADB

JARVIS управляет только устройством, которое пользователь сам подключил и подтвердил в Android Debug Bridge (ADB). Подключение доступно по USB или через Android Wireless debugging в одной локальной сети.

## Подготовка телефона

1. В настройках телефона откройте **О телефоне** и семь раз нажмите **Номер сборки**, чтобы включить меню разработчика.
2. Для сопряжения без кабеля требуется Android 11 или новее и актуальный Android SDK Platform-Tools. В **Для разработчиков** включите **Беспроводную отладку**. Компьютер и планшет должны быть в одной локальной Wi-Fi сети. Android 10 и старше требуют первичного USB-подключения.
3. Подключите телефон по USB и подтвердите на нём запрос **Разрешить отладку по USB**. Не подтверждайте запросы для незнакомых компьютеров.

## Подготовка Windows

1. Установите [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools).
2. Распакуйте архив и добавьте каталог с `adb.exe` в `PATH`. Если не хотите менять `PATH`, задайте переменную окружения `JARVIS_ADB_PATH` с полным путём к `adb.exe`.
3. Для первого сопряжения откройте на планшете **Беспроводная отладка → Сопряжение устройства с помощью кода**. На компьютере в локальном PowerShell выполните `adb pair IP:ПОРТ_СОПРЯЖЕНИЯ`, затем введите код, показанный на планшете. Не отправляйте код в JARVIS или чат.
4. На том же экране планшета найдите основной адрес и порт Wireless debugging (он отличается от pairing-порта). В JARVIS вызовите `android_control` с `action=wifi_connect` и `endpoint=IP:ПОРТ`. Либо локально выполните `adb connect IP:ПОРТ`.
5. Попросите JARVIS проверить подключение. `list_devices` покажет устройства ADB; `status` сообщит модель, версию Android, разрешение экрана и serial. После первичного сопряжения USB больше не нужен, пока компьютер и планшет находятся в одной сети и Wireless debugging включён.

Для проверки из PowerShell можно запустить `adb devices -l`. У телефона должно быть состояние `device`; `unauthorized` означает, что запрос надо подтвердить на самом планшете. Если Wi-Fi адрес или порт сменился, возьмите новые значения на экране Wireless debugging и снова выполните `wifi_connect`. Отключить только Wi-Fi соединение можно через `wifi_disconnect`.

## Команды JARVIS

- Когда Oukitel RT2 подключён к разрешённому ADB, JARVIS автоматически показывает его экран во встроенной панели новостей и результатов. В панели можно нажимать и проводить по изображению, пользоваться кнопками «Домой», «Назад», «Недавние» и отправлять текст с клавиатуры компьютера. Кнопка «Новости» возвращает обычную панель. Для нескольких устройств оставьте подключённым только планшет.
- Прямой ввод с компьютера поддерживает латиницу; русский текст можно вводить экранной клавиатурой планшета. ADB должен оставаться подключённым и авторизованным.
- `status` — подключение, модель, версия Android и размер экрана.
- `get_settings` — прочитать Wi-Fi, Bluetooth, режим полёта, геолокацию, «Не беспокоить», автоповорот, автояркость и яркость.
- `set_setting` — включить или выключить один из этих переключателей через `setting` и `value` (`on`/`off`). JARVIS проверяет состояние после изменения. Включение режима полёта может отключить Wi-Fi и оборвать беспроводное ADB-соединение; для этого переключателя предпочтительно USB-подключение.
- Для остальных пунктов системных настроек используйте интерфейс Android: открыть `com.android.settings`, прочитать экран через `inspect_screen`, нажать нужный элемент и повторно проверить экран. JARVIS не должен обходить блокировку или системные запросы подтверждения.
- `open_app` — запуск приложения по Android package, например `com.android.settings`.
- `inspect_screen` — чтение подписей, accessibility описаний и границ элементов интерфейса; по bounds JARVIS может рассчитать координаты для касания.
- `screenshot` — снимок экрана в `%USERPROFILE%\Pictures\JARVIS\android_screen.png`.
- `tap` и `swipe` — касание и свайп по координатам экрана; сначала попросите снимок экрана, чтобы определить координаты.
- `type_text` — ввод печатного ASCII текста в уже выбранное поле. Стандартная ADB клавиатура не вводит кириллицу. Для неё потребуется установить и вручную включить доверенную ADB Keyboard и выбрать её как текущую клавиатуру.
- `press_key` — `back`, `home`, `recent`, `volume_up`, `volume_down`, `power`, `enter`, `delete`, `space` или `tab`.
- `install_apk` — установить указанный локальный `.apk` с компьютера на выбранный авторизованный планшет; JARVIS использует это только по прямой просьбе установить приложение. APK должен быть уже собран и сохранён на ПК. Для сборки Android-проекта нужны JDK, Gradle и Android SDK; установка готового APK требует только ADB.

Если подключено несколько устройств, укажите `device_id` из вывода `adb devices -l`. ADB имеет широкие права управления телефоном: оставляйте отладку включённой только когда она нужна и отзывайте ранее выданные разрешения в настройках разработчика.
