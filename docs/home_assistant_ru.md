# Home Assistant для JARVIS

Плагин `home_assistant` подключает JARVIS к Home Assistant через REST API. Он умеет находить сущности и читать их состояния, а также управлять разрешёнными доменами: светом, переключателями, сценами, климатом, шторами, вентиляторами, замками, сигнализацией и медиаплеерами.

## Подключение

1. В Home Assistant откройте профиль пользователя и создайте Long-Lived Access Token.
2. В JARVIS откройте палитру команд (`Ctrl+K`), выберите «Настройки плагинов» и найдите Home Assistant.
3. Укажите базовый URL, например `http://homeassistant.local:8123`, и токен. Нажмите «Проверить подключение».
4. Плагин принимает локальный HTTP адрес Home Assistant; для адресов вне локальной сети требуется HTTPS.

Токен хранится в локальной конфигурации плагинов JARVIS. Не отправляйте его в чат и не публикуйте.

## Примеры

- «Какие устройства умного дома доступны?»
- «Какое состояние у лампы в гостиной?»
- «Включи light.living_room»
- «Установи температуру climate.living_room на 22 градуса»

Для управления JARVIS должен сначала найти точный `entity_id`. Разрешены только перечисленные в самом плагине типы сервисов и параметры. Открытие/закрытие штор, управление замками и сигнализацией, а также запуск сценария Home Assistant требуют подтверждения в HUD JARVIS.
