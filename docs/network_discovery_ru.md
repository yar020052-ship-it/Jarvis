# Поиск устройств в локальной сети

Скажите JARVIS: **«Найди устройства в моей сети»**. Действие `network_scan` определяет локальный адрес компьютера по активному маршруту и проверяет только его частную RFC1918-подсеть. Автоматический поиск ограничен 256 адресами.

Сканер использует одиночные ICMP-запросы и проверку распространённых TCP-портов. Он выводит IP-адреса, имена из локального обратного DNS (если доступны) и открытые службы. Вход в устройства, перебор паролей, отправка команд и изменение настроек не выполняются.

Список может быть неполным, если устройство спит, блокирует обнаружение или роутер включает изоляцию клиентов. Обнаружение устройства не предоставляет JARVIS доступ к нему: для управления Android требуется отдельно разрешить ADB на самом устройстве.
