# Локальное распознавание речи

Откройте настройки ассистента и включите «Распознавать речь локально (Windows SAPI)». JARVIS распознаёт речь из уже открытого микрофонного потока через Windows Speech Recognition; отдельная служба распознавания и второй захват микрофона не используются. Для работы установите в Windows речевой компонент для нужного языка и микрофон, который поддерживает диктовку.

Распознавание происходит на компьютере. После него JARVIS показывает распознанную фразу и отправляет текст в Gemini, чтобы ответить или вызвать инструмент. Поэтому этот режим делает локальным только распознавание; он не превращает ассистента в полностью автономную офлайн-модель. Если отключить интернет, текст сможет распознаться локально, но облачная сессия Gemini не обработает запрос.

Режим работает с обычным прослушиванием и push-to-talk. Если Windows SAPI или речевой пакет недоступен, JARVIS один раз сообщит об ошибке в журнале; выключите этот режим в настройках, чтобы вернуть распознавание Gemini Live.
